### [EX]An image file uses 24-bit colour depth.
Describe how 24-bits are used to represent the colour in the file.

RGB → 00000000 11111111 00000000

In a 24-bit color depth image, each pixel is represented by 24 bits, or 3 bytes, of information. This allows for 2^24 possible color combinations, which equals 16,777,216 unique colors.

The 24 bits are typically divided into three 8-bit values, representing the amount of red, green, and blue (RGB) that make up each pixel. This is known as the RGB color model.

Each of the three bytes represents a different color channel, and the value of each byte determines the intensity of that color channel. The range of values for each byte is 0 to 255, with 0 indicating the absence of that color channel and 255 indicating full intensity.

For example, if a pixel has an RGB value of (255, 0, 0), it would be pure red. If the RGB value is (0, 255, 0), it would be pure green, and if the RGB value is (0, 0, 255), it would be pure blue.

Combining different levels of intensity for each color channel creates the full range of colors that can be displayed in the image.

### Analog data vs digital data

1. Analog data: This is continuous data that can take any value within a given range. For example, the sound waves produced by a musical instrument are analog data because they vary continuously over time and can take any value within a certain range of frequencies and amplitudes. Analog data can be represented using physical quantities such as voltage, current, or pressure.
2. Digital data: This is discrete data that is represented using binary digits (bits) that can only have two possible values (0 or 1). For example, a digital audio recording of a musical instrument samples the sound wave at regular intervals, and each sample is represented using a series of bits. Digital data can be easily processed, stored, and transmitted using electronic devices, and it is less susceptible to noise and distortion compared to analog data.

The conversion of analog data to digital data is done through a process called analog-to-digital conversion (ADC), which involves sampling the analog signal at regular intervals and converting each sample into a binary number.
